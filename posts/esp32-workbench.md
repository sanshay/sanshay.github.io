# Turning an ESP32 display board into a tiny workbench

Small ESP32 boards with integrated displays are useful because they remove the friction of wiring a separate screen for every experiment.

## Useful projects

1. Wi-Fi notification panel
2. CAN status monitor
3. BLE scanner
4. Sensor dashboard
5. MQTT control surface
6. Portable test interface

The best projects use the screen for quick feedback while keeping interaction intentionally minimal.
