ABOUT ME

I build software that talks to the real world.

I’m Sanshay Katyal, an embedded software engineer who likes working at the boundary between code, electronics and machines.

Most of my work revolves around connected hardware, vehicle electronics, control systems and the tooling needed to make complex systems understandable.

PROFILE / 01 BUILDING

From firmware to full systems.

I enjoy taking a problem from the first signal on a scope or CAN trace all the way to a working product, dashboard or vehicle subsystem. That means moving comfortably between firmware, networking, sensors, debugging, backend logic and user-facing software.

//

Make the hardware observable. Make the software understandable. Then make the whole system reliable.
